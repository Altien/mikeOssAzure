## OSS PR candidate — Storage provider interface

**Status: IMPLEMENTED** (landed as part of issue 005 + commit `efdb687`)

This document describes the portion of the storage changes that are suitable for
submission upstream to the OSS author. The Azure-specific `AzureBlobProvider`
implementation lives in our fork only and is **not** included in this PR.

## What changed from upstream

The original `backend/src/lib/storage.ts` had flat, module-level functions that
called R2/S3 directly — no abstraction, no way to swap providers.

### `backend/src/lib/storage.ts` refactor

1. **`StorageProvider` interface** (new, exported):

```typescript
export interface StorageProvider {
  upload(key: string, content: ArrayBuffer, contentType: string): Promise<void>;
  download(key: string): Promise<ArrayBuffer | null>;
  remove(key: string): Promise<void>;
  signedUrl(key: string, expiresIn: number, downloadFilename?: string): Promise<string | null>;
}
```

2. **`R2Provider` class** — wraps the original S3/R2 logic verbatim. No
   behaviour change when `R2_ENDPOINT_URL` + `R2_ACCESS_KEY_ID` +
   `R2_SECRET_ACCESS_KEY` are set.

3. **`createProvider()` factory** — selects the implementation based on env vars.
   The four public functions (`uploadFile`, `downloadFile`, `deleteFile`,
   `getSignedUrl`) delegate to the singleton. **Zero call-site changes.**

4. **`storageEnabled`** — now derived from whether a provider was successfully
   constructed; was previously a Boolean env-var check.

## Why this belongs upstream

- Zero behaviour change for any existing R2 deployment.
- Makes it trivial for the OSS community to add new providers (GCS, S3, local
  filesystem for self-hosters) without touching call sites.
- The `StorageProvider` interface is provider-neutral; it carries no Azure or
  Cloudflare imports.

## What stays in the fork (not in the OSS PR)

- `AzureBlobProvider` class and its Azure SDK imports.
- `createProvider()` branch that selects `AzureBlobProvider` on
  `AZURE_STORAGE_ACCOUNT_NAME` / `AZURE_STORAGE_CONNECTION_STRING`.
